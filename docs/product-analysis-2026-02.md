## 2. 현재 제품 분석

### 2.1 냉탐정이 해결하려는 문제

**"냉장고에 이것저것 있는데, 뭐 해먹지?"**

이 질문은 한국 자취생/1인가구가 **매일 반복**하는 문제. 기존 해결 방식과 각각의 한계:

| 기존 방식 | 한계 |
|-----------|------|
| 만개의레시피/해먹 검색 | **레시피 먼저 → 재료 확인** 순서. 내가 가진 재료 기반이 아님 |
| 유튜브 검색 | 영상 10분 보고 나서야 재료 확인 가능. 재료 없으면 시간 낭비 |
| ChatGPT에 직접 물어보기 | 매번 프롬프트 작성, 구조화 안 됨, 장보기 리스트 없음, 이미지 없음 |
| 배달앱 | 비용 문제 (1인 평균 배달비 97,059원/월) |

**냉탐정의 접근**: **재료 먼저 → 레시피 자동 생성** (역방향)

### 2.2 현재 기능 목록

**핵심 기능:**
- 재료 입력 → AI 레시피 3개 생성 (Claude Sonnet 4.5)
- AI 음식 이미지 생성 (Gemini)
- 통합 장보기 리스트 + 쿠팡/네이버 구매 링크
- 3단계 품질 (번개 ~5초 / 기본 ~20초 / 정밀 ~55초)

**정밀 모드 전용:**
- 영양 정보 (칼로리, 단백질, 탄수화물, 지방)
- 대체 재료 제안
- 보관 팁
- YouTube 참고 영상 자동 연결

**사용자 기능:**
- JWT 기반 인증 (회원가입/로그인)
- 보유 재료 관리 (팬트리)
- 검색 기록
- 즐겨찾기
- 카카오톡/Web Share 공유
- 다크 모드

**비즈니스 기능:**
- 비로그인 3회/일 제한, 로그인 무제한
- Google AdSense 광고
- 쿠팡 파트너스 연동

### 2.3 확실한 강점

**A. "재료 → 레시피" 역방향 UX**
- 사용자가 가진 것에서 출발하므로 실행 가능성 100%
- `ingredients_have` / `ingredients_need` 분리로 "뭘 더 사야 하는지" 즉시 파악
- 장보기 리스트 + 쿠팡/네이버 구매 링크까지 원스톱

**B. 15분 시간 제약**
- 자취생에게 1시간짜리 레시피는 의미 없음
- "빠르게 해먹을 수 있는 것"에 집중한 포지셔닝이 명확

**C. AI 개인화**
- 조리도구 선택 (프라이팬만 있는 자취생 vs 에어프라이어 보유자)
- 제외 재료/알레르기 반영
- 매번 다른 레시피 생성 (기존 DB 기반 앱은 같은 검색 → 같은 결과)

**D. 정밀 모드의 부가가치**
- 영양 정보, 대체 재료, 보관 팁, YouTube 참고 영상
- "요리 초보"에게 특히 유용

### 2.4 솔직한 약점

**A. 레시피 신뢰도**
- AI 생성 레시피는 "검증된 레시피"가 아님
- 만개의레시피는 수십만 건의 실제 후기/평점이 있음
- 사용자가 "이거 진짜 맛있어?" 확인할 방법이 없음

**B. 커뮤니티/소셜 부재**
- 레시피 평가, 후기, 사진 공유 기능 없음
- "혼자 쓰는 도구"에 머물고 있음

**C. 반복 사용 동기 부족**
- 매일 돌아올 이유가 약함 (피드, 알림, 목표 없음)
- 보유 재료 관리가 수동
- 새로운 콘텐츠/추천이 없음

**D. 비용 구조**
- Claude API + Gemini 이미지 생성 = 요청당 비용 발생
- 사용자가 늘수록 비용이 선형 증가

## 3. 12 페르소나 심층 분석

### 페르소나 1: 자취 초보 대학생 "민지" (20, 여)

```
상황: 대학 입학 후 첫 자취. 라면, 계란프라이만 할 줄 앎
월 식비: 35만원 (부모 지원 + 아르바이트)
요리 빈도: 주 2-3회 (나머지는 배달/편의점)
기기: 전자레인지, 1구 인덕션, 냄비 1개
```

- **현재 행동**: 유튜브 "자취 요리" 검색 → 재료 확인 → "이거 없는데..." → 배달앱
- **냉탐정 가치**: ★★★★★ (최고)
  - "계란, 라면, 김치"만 입력하면 만들 수 있는 게 나옴
  - 요리 자체를 학습하는 과정에서 가치 극대화
  - 장보기 리스트가 "뭘 사야 하는지 모르는" 초보에게 필수
- **구독 의향**: ★★☆☆☆ (낮음)
  - 예산 제한이 큼. 무료만 쓸 가능성 높음
  - 하지만 "월 4,900원으로 배달비 3만원 절약" 프레이밍이면 가능성 있음
- **이탈 시점**: 6개월 후 기본 요리 5-6개 레퍼토리 생기면 사용 빈도 감소

### 페르소나 2: 야근 직장인 "준혁" (28, 남)

```
상황: IT 회사 3년차. 퇴근 9시. 지쳐서 매일 배달
월 식비: 55만원 (배달 주 4회 × 15,000원 = 24만원)
요리 빈도: 주 1-2회 (주말에 가끔)
기기: 에어프라이어, 전자레인지, 프라이팬
```

- **현재 행동**: 배달의민족 → 쿠팡이츠 → "또 치킨이네..." → 자기혐오
- **냉탐정 가치**: ★★★★☆
  - 10분 레시피가 핵심 — "퇴근 후 10분이면 끝"
  - 에어프라이어 활용 레시피가 라이프체인저
  - 식비 절약 효과가 가장 큼 (배달 → 자취 요리 전환)
- **구독 의향**: ★★★★☆ (높음)
  - 돈은 있지만 시간이 없음
  - "주간 식단 자동 생성 + 일요일 장보기 리스트"에 기꺼이 지불
  - 월 9,900원도 배달 1회 비용보다 저렴
- **핵심 요구**: 주간 식단 플래닝, "오늘 뭐 먹지" 푸시 알림

### 페르소나 3: 다이어트 중인 헬스인 "수진" (25, 여)

```
상황: 헬스 3개월차. 체중 감량 목표 -5kg. 식단 관리가 핵심
월 식비: 45만원 (닭가슴살, 샐러드 위주)
요리 빈도: 매일 (밀프렙 주 1회)
기기: 풀 장비 (에어프라이어, 오븐, 블렌더)
```

- **현재 행동**: 밀리그램 앱으로 칼로리 기록 + 유튜브 "다이어트 식단"
- **냉탐정 가치**: ★★★☆☆ (중간)
  - 영양 정보(정밀 모드)가 유용
  - 하지만 칼로리/매크로 목표 설정이 없으면 반쪽짜리
  - "오늘 단백질 30g 더 필요해요, 이 재료로 이걸 만드세요"가 필요
- **구독 의향**: ★★★★★ (매우 높음) — 단, 기능이 있다면
  - 다이어트 앱에 이미 월 9,900~19,900원 지불 중
  - 밀리그램(120만 유저)이 증명한 시장
  - 식단 + 영양 + 요리를 통합하면 구독 전환 최고
- **핵심 요구**: 칼로리/매크로 목표 설정, 일일 영양 트래킹, 식단 자동 생성

### 페르소나 4: 극한 식비절약러 "현우" (24, 남)

```
상황: 대학원생. 월 생활비 80만원. 식비를 20만원 이하로 관리
요리 빈도: 매일 (거의 외식 안 함)
기기: 냄비, 프라이팬
```

- **현재 행동**: 마트 할인 재료 구매 → 같은 메뉴 반복 (김찌+계란)
- **냉탐정 가치**: ★★★★☆
  - 같은 재료로 다른 메뉴를 만들 수 있다는 게 핵심
  - 장보기 리스트의 최소화가 중요 (추가 재료 최소)
  - "이 재료들로 3일치 식단" 기능이 있으면 최고
- **구독 의향**: ★☆☆☆☆ (매우 낮음)
  - 식비 아끼려는 사람에게 구독비는 모순
  - 무료 사용자이면서 DAU를 올리는 역할 → 광고 수익 대상
  - 커뮤니티 후기 작성자로 가치 있음

  - 둘이 쓰면 월 4,900원은 부담 없음

월 식비: 90만원 (3인)
요리 빈도: 매일 (의무)

- **현재 행동**: 마켓컬리 밀키트 주 2회 + 직접 요리 + 배달
- **냉탐정 가치**: ★★★★☆
  - 밀키트 대체가 핵심 가치 (밀키트 1회 12,000원 vs 냉탐정으로 직접 요리)
  - "아이가 먹을 수 있는" 필터가 필수 (매운 거 제외 등)
  - 주간 식단이 시간 절약에 핵심
- **구독 의향**: ★★★★☆

  - "밀키트 없이 밀키트처럼"이라는 포지셔닝이면 월 9,900원은 가성비 좋음
  - 단, 아이 식단, 알레르기 관리 등 가족 기능 필요
- **핵심 요구**: 가족 인원/연령 설정, 아이 식단, 주간 계획, 밀키트 수준 상세 레시피

상황: 유제품 알레르기 + 채식 지향. 한국에서 비건 레시피 찾기 어려움
월 식비: 50만원

## 6. 냉정한 판단 — 현재 냉탐정은 구독 가치가 있는가?

### 결론: 현재 상태로는 **없다.**

지금의 냉탐정은 **"신기한 1회성 도구"**. 솔직하게 말하면:

**구독하지 않을 이유:**
1. ChatGPT에 "계란, 김치로 뭐 해먹지?" 물으면 비슷한 답이 나옴
2. 3회/일 무료면 대부분의 일반 사용자에겐 충분
3. 매일 돌아올 이유가 없음 (피드, 알림, 목표 없음)
4. 레시피 품질을 검증할 수 없음 (후기, 평점 없음)
5. "이 앱이 나에게 얼마를 절약해줬는지" 보이지 않음

**구독할 이유가 되려면 필요한 것:**

> "이 앱이 매월 나에게 **측정 가능한 가치**를 준다"는 것을 느껴야 함

## 7. 방향 전환 제안 — "레시피 생성기"에서 "AI 식생활 어시스턴트"로

### 7.1 전환 개요

```
현재: 재료 입력 → 레시피 3개 (도구)
전환: 내 식생활을 통째로 관리해주는 AI 어시스턴트 (서비스)
```

### 7.2 구독 전환을 이끄는 핵심 기능 3가지

#### 기능 1: 주간 식단 자동 생성 (구독 전환율 1위 예측)

```
일요일 저녁, 푸시 알림:
"다음 주 식단이 준비됐어요! 장보기 리스트도 만들었어요"

[월] 김치볶음밥, [화] 된장찌개, [수] 참치마요덮밥...
→ 통합 장보기: 계란 1판, 두부 2모, 대파 1단...
→ 쿠팡 바로 구매 (원클릭)
```

- 매주 반복 가치 → 구독 유지 이유
- "메뉴 고민" 시간 제로 → 직장인/부부에게 킬러 기능
- 장보기 통합 → 쿠팡 파트너스 수익도 연결
- **대상 페르소나**: ②준혁, ⑤신혼부부, ⑥은정, ⑨성민

#### 기능 2: 영양 목표 + 트래킹 (구독 가격 상승 근거)

```
오늘 목표: 1,800kcal / 단백질 120g
점심에 "닭가슴살 볶음밥" 먹음 → 기록
→ "저녁에 단백질 40g 더 필요해요. 두부로 이걸 만들어보세요"
```

- 밀리그램(120만 유저)이 증명한 시장
- 식단 기록 + 레시피 생성을 통합한 앱이 **없음**
- 다이어트/헬스 시장 진입 근거
- **대상 페르소나**: ③수진, ⑩정숙

#### 기능 3: 식비 리포트 (구독 유지 근거)

```
이번 달 식비 리포트:
- 자취 요리: 28회 (총 187,000원)
- 배달/외식: 8회 (총 134,000원)
- 지난달 대비 식비 23,000원 절약!
- 냉탐정 사용으로 추정 절약액: 월 45,000원
```

- "구독비 4,900원 vs 절약 45,000원" = **9배 ROI**
- 숫자가 보이면 해지율 급감
- "이 앱 덕분에 돈 아꼈다"는 입소문
- **대상 페르소나**: ②준혁, ④현우, ⑨성민

## 10. 투자 가치 판단

### 10.1 투자할 만한 이유

1. **"재료 → 레시피" 역방향은 경쟁사가 못 하는 것** — 만개의레시피는 DB 기반, AI 생성 전환 어려움
2. **식비 42만원 시장** — 1인가구 750만 × 42만원 = 월 3.15조원 식비 시장
3. **구독 피로를 넘는 실질 가치** — "절약액 > 구독비"가 증명되면 해지율 낮음
4. **글로벌 확장 가능** — 한식 한류 + 다국어 → 해외 시장 (K-Recipe AI)
5. **AI 네이티브** — 기존 레시피앱은 DB→AI 전환이 어렵지만, 냉탐정은 처음부터 AI
6. **유료 레시피앱 성장률(14% CAGR)이 무료(10%)보다 빠름** — 시장 방향과 일치

### 10.2 투자하지 말아야 할 이유

1. **ChatGPT가 무료로 비슷한 걸 해줌** — AI 레시피만으로는 moat이 약함
2. **한국에서 레시피앱 유료 구독 성공 사례 0건** — 시장 검증 안 됨
3. **레시피 품질 검증 불가** — 커뮤니티 없으면 신뢰도 한계
4. **단독 1인 개발** — 스케일 한계
5. **구독 전환 5%가 낙관적일 수 있음** — 한국 구독 피로도 높음

### 10.3 최종 판단

> **현재 "레시피 생성기"로는 투자 가치 없음.**
> **"AI 식생활 어시스턴트"로 전환하면 투자 가치 있음.**

전환의 핵심:
- 1회성 도구 → **매일 쓰는 서비스** (주간 식단, 알림, 트래킹)
- "신기하다" → **"이거 없으면 불편하다"** (습관 형성)
- 레시피만 → **식비 절약 + 건강 관리** (측정 가능한 가치)

## 한 문장 요약

> 냉탐정의 "재료→레시피" 핵심은 강력하지만, **"1회 도구"를 "매일 쓰는 식생활 어시스턴트"로 전환**해야 구독 가치가 생기고, 그때 비로소 투자할 만한 서비스가 됩니다. 핵심은 **주간 식단 + 영양 트래킹 + 식비 절약 증명** — 이 세 가지가 구독을 만들고, 유지하고, 확산시킵니다.
